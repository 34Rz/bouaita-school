# نظام إدارة المدرسة
نسخة أولية مشابهة للفكرة الظاهرة في الفيديو: لوحة تحكم عربية RTL، قائمة جانبية خضراء، إحصائيات، الطلاب، الأساتذة، الأقسام، الحضور، النقط، الجدول، الإعلانات والإعدادات.

## التشغيل
افتح ملف `index.html` مباشرة في Chrome أو Edge.
هذه نسخة واجهة Front-End تجريبية، ويمكن في المرحلة التالية ربطها بقاعدة بيانات/Google Sheets وإضافة تسجيل الدخول وصلاحيات الإدارة والأساتذة والطلاب.
